      Axis one · the calendar
      
A different companion every day

      

        The date is hashed into a seed, and the seed picks species, name, colours, and accessories.
        No assets ship with the app — everything here is drawn from the seed. The same date gives
        the same creature on every machine, so you and a teammate see the same one.
      

    

    

  


  

    

      Axis two · the repository
      
One companion, seven moods

      

        Mood is read from the last 24 hours of commits by the same ontology engine that
        classifies commit intent. Appearance is held fixed here so only the state changes.
